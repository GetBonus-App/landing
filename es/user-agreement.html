Términos de servicio

1. Disposiciones generales

1.1. GetBonus es una plataforma en la que los usuarios completan tareas (ofertas CPA) y reciben una recompensa en forma de moneda de bonificación (Telegram Stars).

1.2. El Servicio está disponible a través de Telegram y no requiere un registro aparte: la autorización se realiza mediante el ID de Telegram.

2. Aceptación de las condiciones

2.1. Al utilizar el Servicio, confirmas que:

  • tienes plena capacidad jurídica;
  • aceptas las condiciones de este Acuerdo y de la Política de privacidad;
  • no infringes la legislación de la Federación de Rusia ni las normas internacionales.

2.2. Si no estás de acuerdo con las condiciones, debes dejar de utilizar el Servicio.

3. Descripción del servicio

3.1. El Usuario puede completar tareas de los socios y recibir una recompensa.

3.2. La recompensa se abona cuando el sistema del socio confirma que la tarea se ha completado.

3.3. La moneda interna del Servicio, Telegram Stars, se utiliza para la contabilidad interna y puede retirarse si se cumplen las condiciones.

4. Obligaciones del usuario

El Usuario se compromete a:

  • no utilizar multicuentas, bots ni métodos para eludir el sistema;
  • facilitar datos veraces al completar las tareas;
  • no realizar acciones que alteren el funcionamiento del Servicio;
  • respetar las restricciones establecidas por los socios para sus tareas (edad, región, condiciones de participación).

5. Recompensas y pagos

5.1. La recompensa solo se abona cuando el socio confirma que la tarea se ha completado.

5.2. El Servicio no se hace responsable de los retrasos ni de la negativa del anunciante a confirmar una tarea.

5.3. Los pagos de bonos pueden restringirse en caso de incumplimiento de las condiciones, intento de engaño, uso de cuentas duplicadas, fraude y conductas similares.

6. Limitación de responsabilidad

6.1. El Servicio se presta «tal cual». No garantizamos un funcionamiento ininterrumpido ni libre de errores.

6.2. No nos hacemos responsables de los fallos causados por Telegram, ofertas de terceros, incidencias técnicas o acciones de los usuarios.

7. Bloqueo y eliminación de la cuenta

El Servicio se reserva el derecho a:

  • restringir temporalmente la funcionalidad o bloquear una cuenta ante la sospecha de una infracción;
  • eliminar de forma permanente los datos de un usuario cuando se confirme fraude o incumplimiento de las condiciones.

8. Modificación de las condiciones

El Servicio puede modificar las condiciones de este Acuerdo en cualquier momento.
